# Presentationen

`redovisning.html` är källan till redovisningsdäcket (13 slides, torsdag 11/9).

## Titta på den

- **Publicerad version** (den vi kör på): länken Henrik delat i gruppkanalen.
- **Lokalt:** öppna `docs/presentation/redovisning.html` direkt i webbläsaren
  — ingen server, inget bygge. Dubbelklicka bara på filen.

## Styrning

| Tangent | Gör |
|---|---|
| `→` `mellanslag` | Nästa slide |
| `←` | Föregående |
| `F` | Helskärm |
| `Home` / `End` | Första / sista |

Klick går också framåt — men inte när du markerat text, så du kan läsa upp
citat utan att sidan hoppar. Nere till vänster syns **vem som pratar** och
**vilken tid** sliden hör till.

## Ändra något

Filen är vanlig HTML i ett stycke — ingen byggkedja, inga beroenden.

1. Redigera `redovisning.html`
2. Öppna den i webbläsaren och kontrollera
3. PR mot `main` som vanligt

Henrik publicerar om den efter merge, så den delade länken uppdateras.
Innehållet följer `docs/demo-manus.md` — ändrar du en siffra på en slide,
ändra den i manuset också (och tvärtom).
